# 使用指南

[返回 README](../README.md) · [English](usage-en.md)

## 创建与运行对话

1. 点击右上角 `+`，从服务端目录选择器中选定项目工作目录。
2. 输入任务；需要时使用输入区左下角的 `+` 上传图片或普通文件，也可直接粘贴图片。
3. 选择审批策略、模型和推理强度；在“高级”中选择只读、工作区可写或完全访问沙箱。
4. 发送后可查看流式回复与工具事件。任务运行期间可以暂停，断线后页面会尝试恢复并补收事件。

## 管理对话

- 桌面端使用左侧栏，移动端通过左上角菜单打开会话抽屉。
- 对话按工作目录分组并显示运行状态；点击条目可恢复历史上下文。
- 可以归档单个对话、整个项目分组或全部对话。归档正在运行的对话前需先暂停任务。
- 每个对话独立保留模型、推理强度、沙箱、审批设置和输入草稿。

## 附件与文件预览

- 图片作为 Codex 原生图片输入传递；普通文件通过受控的本地路径上下文传递。
- 上传完成后再发送消息。默认单文件上限为 64 MB。
- 本地 Markdown、JSON、SVG、图片和视频路径会自动变成预览链接。
- Markdown 默认在对话内弹窗渲染，并支持 `file.md:行号` 与 `file.md:行号:列号` 链接。
- 图片可在对话内放大，视频可直接播放；允许的扩展名和预览大小可在设置中调整。

## 审批与终端

“请求批准”或“谨慎模式”下，命令、文件修改和额外权限会弹出确认。可以拒绝、仅批准一次，或在当前会话中允许。

顶栏终端按钮会打开当前工作目录下的 PTY 终端。移动端提供粘贴、触控选择和复制操作。终端拥有运行 WebUI 的系统用户权限，请谨慎开放远程访问。

## MCP、Skill 与 Plugin

- 在“设置 → MCP 服务”中搜索、添加、更新或移除 STDIO/流式 HTTP MCP Server。
- 在“设置 → Skills 与插件”中刷新并搜索扩展，安装或移除 Plugin，以及启用或禁用本地 `SKILL.md`。
